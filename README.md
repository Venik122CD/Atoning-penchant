# Atoning Penchant

Компат-мод **Caverns & Chasms + Penchant** для **NeoForge 1.21.1**.
Атонинг-стол получает механику и окно стола зачарований Penchant, а платить за чары нужно по правилам C&C.

## Как это работает в игре

Слоты слева направо: **шпинель**, **предмет**, **лазурит** (или книга - для снятия чар).

Всё как в столе Penchant:
- список чар с прокруткой; чары, которых нет в обычном столе, «открываются» зачарованными книгами в резных
  книжных полках рядом (неоткрытые пишутся галактическим шрифтом);
- у каждой чары есть требование по книгам (счётчик книг слева), несовместимые и уже наложенные чары блокируются;
- индикатор наждачного камня: с ним в правый слот можно класть книгу и **снимать чары** на неё;
- чара накладывается на 1-м уровне и дальше прокачивается системой Penchant;
- достижения Penchant (открыть стол, снять чару) тоже выдаются.

Как в C&C:
- платишь **шпинелью, лазуритом и прочностью**: уровень i (1..3) стоит i шпинели + i лазурита и
  `min(100%, 25%*i + random*27.5%)` максимальной прочности. Предмет может сломаться (достижение «Atone-Deaf»);
- предмет должен иметь прочность (книгу «искупить» нельзя).

Новое - **кинжал над книгой** (тултип: «Нажми на кинжал, чтобы изменить уровень зачарования»):

| Уровень (цвет) | Цена | Что получаешь |
|---|---|---|
| Лёгкий (зелёный) | 1 + 1, 25-52% | чара 1 уровня, прогресс 0 (как у Penchant) |
| Нормальный (оранжевый) | 2 + 2, 50-77% | 30-75% пути до максимального уровня: «почти 2 уровень» или уже 2 |
| Сложный (красный) | 3 + 3, 75-100% | 30%: сразу максимальный уровень, иначе 60-95% пути |

Чары, которые не прокачиваются (максимум 1 уровень или тег `penchant:no_leveling`), всегда идут по
лёгкому уровню. Книга открыта, когда есть что выбирать, закрыта - если предмета нет или он не подходит;
кинжал качается вверх-вниз только при открытой книге (та же синусоида, что у частицы-кинжала C&C).

**Числа подгоняй под баланс в `AtoningCosts.java`** (проценты, шанс, доли пути).

## Сборка

1. Положи jar **Caverns & Chasms** (`caverns_and_chasms-1.21.1-3.0.1.jar`) в `libs/` (нужен только для компиляции).
2. `./gradlew build` (Java 21) -> `build/libs/atoning_penchant-1.0.0.jar`.

## Установка / тест

В сборке (NeoForge 1.21.1): C&C 3.0.1 + Blueprint, **Sinytra Connector** + Forgified Fabric API, Penchant, этот мод.
`runClient` из IDE не заработает (нет Penchant/Connector) - тестируй в реальной сборке.

## Замечания

- **Проект не собирался.** Писался без интернета: синтаксис проверен компилятором, но имена методов Minecraft/NeoForge
  могут потребовать правки при первой сборке. Присылай лог - поправлю.
- **Penchant 0.3.7 и 0.3.12.** Мод не компилируется против классов Penchant (читает данные и использует рефлексию с
  запасными значениями), но тег `no_leveling` есть только в более новых версиях.
- **Лицензии.** Кода C&C и Penchant в проекте нет, jar'ы не включены. Лицензия C&C запрещает их распространять
  (`libs/*.jar` в `.gitignore`).
- Не перенесены: подсказки Item Descriptions (необязательный мод Penchant).
